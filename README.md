A web application made for the XHacks SFU Hackathon.

Users may create new chats or pull up old chats, and speak directly to an ai tuned to behave as if it was Socrates himself.

to use this AI, first run the server using the 'node server.js' command, then launch via live server.
If you don't receive a response in a timely manner, try replacing the api key with a new Gemini key.
